# V8 — Beta master runbook (Day −14 → Day 30)

Australian English. The end‑to‑end operating sequence with **entry/exit gates**, an **owner**, and the **evidence**
required to pass each gate. Owner is **Abdul** unless marked Codex. Manual‑entry beta; no provider dependency.

## Phase 0 — Prep (Day −14 → Day −8)
- **Do:** finalise the invite shortlist (≥30 SA prospects); confirm screening form + invites; brief
  `../support_playbook.md`; set up `kpi_dashboard_template.csv` + `participant_pipeline_template.csv`; confirm
  disclaimers placed (`../trust_safety_disclosures.md`).
- **Entry gate:** commercial kit ready. **Exit gate:** shortlist ≥30 + templates live + disclaimers placed.
- **Evidence:** pipeline populated (initials only); scorecard dimensions 3–7 trending Ready.

## Phase 1 — Go/No‑Go (Day −7)
- **Do:** run `go_no_go_scorecard.md` with Codex (technical) + Abdul (business).
- **Entry gate:** Phase 0 exit met. **Exit gate:** **GO** or **CONDITIONAL GO** (with wave size).
- **Evidence:** signed scorecard; #1 technical, #2 usefulness, #4 trust/safety all Ready.

## Phase 2 — Recruit & screen (Day −7 → Day −1)
- **Do:** send personalised invites (network/referral/waitlist first); screen respondents (`../screening_form.md`);
  capture consent; schedule wave(s).
- **Entry gate:** GO/CONDITIONAL GO. **Exit gate:** ~25 screened‑in + consented (or the CONDITIONAL first wave).
- **Evidence:** pipeline shows screened_in + consent captured; ≥25 accepts (or wave target).

## Phase 3 — Onboard & activate (Day 1 → Day 7)
- **Do:** send `../onboarding_guide.md`; get each participant to a **first Deal Brief**; **same‑day unblock**
  anyone stuck; log friction (`../feedback_taxonomy.md`).
- **Entry gate:** screened + consented. **Exit gate:** **activation ≥60%** of invited.
- **Evidence:** activation count in the KPI dashboard; friction log.

## Phase 4 — Use & learn (Day 7 → Day 23)
- **Do:** weekly "bring a real deal" nudge; **day‑7 survey** fires per participant; 2–3 **interviews/week**
  (`../user_interview_script.md`); Mon metrics board; Fri ship ≤1 proven fix + "what changed" note.
- **Entry gate:** activation gate met. **Exit gate:** **7‑day return ≥40%** + usefulness trending **≥4.0**.
- **Evidence:** return + usefulness in the dashboard; interview notes tagged.

## Phase 5 — Willingness‑to‑pay (Day 23 → Day 29)
- **Do:** WTP + pricing conversation in interviews + prep the **day‑30 survey** (`../pricing_research_plan.md`);
  probe $9/$19/$29 + per‑report (no public price).
- **Entry gate:** value signal positive. **Exit gate:** WTP data collected from a clear majority of active users.
- **Evidence:** WTP responses + price band (hypothesis).

## Phase 6 — Closeout & decision (Day 30)
- **Do:** send **day‑30 survey**; final interviews; compute KPIs vs the four targets; write the **go/no‑go memo**
  (`post_beta_decision_framework.md`); thank participants (no pricing commitment); **cleanup** any UAT/test data is
  **Codex‑owned**.
- **Entry gate:** Phases 3–5 complete. **Exit gate:** a **single chosen outcome** with cited evidence.
- **Evidence:** completed scorecard of the four targets; the memo; ranked roadmap themes.

## Standing rules
1‑business‑day support; weekly Mon/Wed/Fri cadence; log everything (initials only, no PII in the repo); never claim
valuation/advice or licensed data; escalate legal/privacy/upset‑user issues to Abdul. Technical actions (Preview,
UAT, cleanup) are **Codex‑owned** — this runbook coordinates, it does not perform them.
