# V8 — Beta calendar

Australian English. Daily detail for launch week; weekly cadence thereafter. Pairs with `beta_master_runbook.md`.
Times are indicative; keep the founder load ~3–5 hrs/week.

## Pre‑launch week (Day −7 → Day −1)
| Day | Activity |
|---|---|
| −7 | Run Go/No‑Go scorecard (with Codex). Send first personalised invites (network/waitlist). |
| −6 | Screen respondents; schedule wave 1. |
| −5 | More invites (referrals); confirm consent captured. |
| −4 | Confirm disclaimers + onboarding guide + support scripts ready. |
| −3 | Finalise ~25 (or CONDITIONAL first wave); buffer waitlist. |
| −2 | Dry‑run onboarding on your own account; confirm first‑Deal‑Brief path is smooth. |
| −1 | Final Go/No‑Go confirm; queue Day‑1 welcome messages. |

## Launch week (Day 1 → Day 7) — daily
| Day | Activity | Comms | Metrics |
|---|---|---|---|
| 1 | Wave 1 onboarded (~12). Watch first activations. | Welcome + quick‑start | activation start |
| 2 | Same‑day unblock; log friction. | 1:1 nudges to non‑activated | activation |
| 3 | Wave 2 onboarded (~12). | Welcome wave 2 | activation |
| 4 | 2 user interviews. | check‑in with active users | activation, first briefs |
| 5 | Ship first small fix; "what changed" note. | what‑changed note | properties analysed |
| 6 | Nudge "bring a real deal". | nudge | saves/compares |
| 7 | **Day‑7 survey** fires (per participant, rolling). Weekly metrics board. | day‑7 survey | activation ≥60%? |

## Weeks 2–3 (Day 8 → Day 23) — weekly rhythm
| Cadence | Activity |
|---|---|
| **Mon** | Pull KPI board; set weekly focus; review risk register. |
| **Tue** | Outreach/referrals; pipeline update. |
| **Wed** | 2–3 user interviews. |
| **Thu** | 1 partner conversation (Stage‑2 seed). |
| **Fri** | Ship ≤1 proven fix; "what changed" note; ask happy users for a referral/testimonial (with permission). |
| Daily | Respond to participants within 1 business day. |

## Week 4 (Day 24 → Day 30) — closeout
| Day | Activity |
|---|---|
| 24–28 | WTP/pricing conversations; final interviews. |
| 29 | Prep + send **day‑30 survey**. |
| 30 | Compute KPIs vs targets; write go/no‑go memo; thank participants. |

## Review cadences
- **Metrics review:** weekly (**Mon**) against the four targets + supporting metrics.
- **Incident review:** **as they occur** (same day for anything trust/safety, data, or a blocked participant),
  plus a brief weekly look at the **risk register** (`risk_register.csv`) — update likelihood/impact/status.
- **Founder‑sales routine:** the Tue–Fri blocks above (`../../../commercial/v8_provider_outreach/scale_strategy/founder_sales_playbook.md`).

## Participant communications summary
Welcome/quick‑start (Day 1–3) → weekly "bring a real deal" nudge → day‑7 survey → interview invites → "what changed"
notes (Fri) → day‑30 survey → thank‑you + what's next (no pricing commitment). All honest, invite‑only, no
valuation/advice or licensed‑data claims.
