# V8 — Post‑beta decision framework

Australian English. At Day 30, pick **one** direction, tied to **measurable evidence** — not vibes. Uses the four
targets (activation ≥60%, 7‑day return ≥40%, usefulness ≥4.0, WTP ≥40%) + qualitative signal. Cross‑reference
`go_no_go_scorecard.md`, `kpi_dashboard_template.csv`, `../day_30_survey.md`, `../user_interview_script.md`.

## The six outcomes → evidence that triggers each
| Outcome | Trigger (evidence) | Then |
|---|---|---|
| **1. Continue** (build v1, start paid conversion) | **all four targets met** (activation ≥60%, return ≥40%, usefulness ≥4.0, WTP ≥40%) | proceed to Stage 2 (`../../../commercial/v8_provider_outreach/scale_strategy/twelve_month_growth_roadmap.md`); run the first pricing experiment |
| **2. Extend beta** (another 30 days) | **most** targets met but one is borderline (e.g., activation 40–60% **or** return 25–40%); usefulness ≥4.0 | fix the top‑2 frictions (`../feedback_taxonomy.md`); re‑run the cohort; re‑test |
| **3. Narrow segment** | strong usefulness/WTP in **one sub‑segment** but weak overall | re‑scope to the sub‑segment that loves it; re‑message (`../../../commercial/v8_provider_outreach/scale_strategy/market_positioning.md`); re‑test |
| **4. Change pricing** | usefulness high **but** WTP <40% at the tested price | test a lower price / **per‑report** / different value framing before concluding "won't pay" |
| **5. Pause** | usefulness <3.0 **or** activation <40% (core value not landing) | stop acquisition; deep problem‑discovery interviews; re‑examine the value prop before more build |
| **6. Seek provider agreement** | value proven **and** manual entry is the main friction, **and** unit economics justify `[PROVIDER_COST]` | begin Domain outreach (`../../../commercial/v8_provider_outreach/scale_strategy/provider_negotiation_strategy.md`); sign only if margin holds (business model §D) |

## Decision rules
- **Evidence first:** each outcome must cite the specific metric(s) that triggered it.
- **One direction:** don't do everything — pick the outcome the evidence most supports.
- **Trust is a veto:** if trust/safety signals are poor (users misreading output as advice/valuation, or a
  data/privacy concern), address that **before** any growth move, regardless of other metrics.
- **Provider data never gates the pivot:** outcomes 1–5 can proceed on manual entry; only outcome 6 involves a feed.

## Output: the go/no‑go memo (Day 30)
One page: metrics vs targets · top themes (`../feedback_taxonomy.md`) · WTP + price band (hypothesis) · chosen outcome
+ the evidence for it · next 30‑day plan + owner. Filed here and summarised in `README.md` status.
