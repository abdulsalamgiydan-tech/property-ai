# Launch checklist — SA founding beta

> Pre‑launch → run → close. This kit is **documentation only**; the technical Preview/access items below are
> **owned by Codex** and listed here for coordination — this workstream does not perform them. Australian English.

## Pre‑launch (Week 0)
**Commercial/kit (this workstream)**
- ☐ `../../commercial/v8_provider_outreach/abdul_decisions.md` six inputs filled (entity, ABN, contact, pilot size, volume, model).
- ☐ Invite list shortlisted (~30 to land ~25 activated); screening form ready.
- ☐ Invitation email + DM personalised; landing copy reviewed.
- ☐ Onboarding guide, expectations, FAQ ready to send.
- ☐ Support playbook briefed; response targets agreed.
- ☐ Surveys (day‑7, day‑30) + interview script scheduled; KPI tracker sheet set up.
- ☐ Trust & safety disclosures placed in copy (not‑advice, labelling, no‑scraping, no licensed‑data claim).

**Technical readiness (Codex‑owned — confirm, do not perform here)**
- ☐ V8 Preview is live, invite‑only gating on, and the desktop/mobile UAT has passed.
- ☐ "Confirm before scoring incomplete facts" behaves as described.
- ☐ Source/fact/estimate labelling visible in the product.
- ☐ Data deletion path available for participant requests.

## Launch (Week 1)
- ☐ Send invites in 2 waves (~12 each).
- ☐ Confirm each accepted participant reaches a first Deal Brief (activation).
- ☐ Same‑day unblock for anyone stuck; log friction.

## Run (Weeks 2–3)
- ☐ Weekly "bring a real deal" nudge.
- ☐ 3 user interviews/week.
- ☐ Mon metrics board; Fri ship ≤1 proven fix + "what changed" note.
- ☐ Day‑7 survey fires per participant.

## Close (Week 4)
- ☐ Day‑30 survey + final interviews.
- ☐ Compute KPIs vs targets (activation ≥60%, return ≥40%, usefulness ≥4.0, WTP ≥40%).
- ☐ Pricing signals summarised (as hypotheses).
- ☐ **Go/no‑go memo** written; roadmap top‑themes ranked.
- ☐ Thank participants; outline what's next (no pricing commitment).

## Do‑not (all weeks)
No scraping; no valuation/advice claims; no claim of licensed live provider data; no pricing commitments; no
provider outreach without Abdul's six inputs + approval; no changes to infrastructure/app/UAT (Codex‑owned).
